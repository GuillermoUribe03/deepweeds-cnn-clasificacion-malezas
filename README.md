# Clasificación de malezas con CNN y Transfer Learning (DeepWeeds)
 
Proyecto final del curso **Fundamentos de Deep Learning**, desarrollado como parte de mi portafolio profesional y académico. El objetivo es clasificar especies de malezas a partir de imágenes RGB usando redes convolucionales y transfer learning (Módulo 4), aplicando el conocimiento a un problema con potencial relevancia para agricultura de precisión y, por extensión, a tareas de reconocimiento visual en terreno (p. ej. clasificación de material en minería).

## Dataset
 
**DeepWeeds**: 17,509 imágenes RGB de 256×256 px, 9 clases (8 especies de maleza + clase "Negative"), recolectadas en terreno en pastizales de Queensland, Australia, con un robot de fumigación selectiva.
 
- Tomado de: [Kaggle](https://www.kaggle.com/datasets/imsparsh/deepweeds) (también disponible en el repositorio oficial de A. Olsen en GitHub, [github.com/AlexOlsen/DeepWeeds](https://github.com/AlexOlsen/DeepWeeds)).
- Paper de referencia: A. Olsen et al., "DeepWeeds: A Multiclass Weed Species Image Dataset for Deep Learning," *Scientific Reports*, vol. 9, art. 2058, 2019.
